# FutBot Omni: robótica móvil

Proyectos del robot omnidireccional de 3 ruedas **FutBot Omni** (Raspberry Pi 5 + Arduino Mega 2560 +
Adafruit Motor Shield V2, encoders de 120 cuentas por vuelta, IMU BNO085).
Universidad Politécnica de Yucatán, Ingeniería en Robótica Computacional.

| Carpeta | Proyecto | Estado |
|---|---|---|
| [`tarea_velocidad_u3/`](tarea_velocidad_u3/) | AMR Assessment 1 Unit 3: control de velocidad de rueda P/PID y trayectorias omni (recta, círculo, cuadrado) | Activo |

Cada carpeta tiene su propio README con cómo correrla.
